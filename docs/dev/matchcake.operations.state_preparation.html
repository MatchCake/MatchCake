class matchcake.operations.state_preparation.gaussian_state_prep.GaussianStatePrep(covariance_matrix: int | float | bool | complex | bytes | list | tuple | ndarray | generic | ArrayBox | InterfaceTensor | Tensor | Number, wires: Wires | Iterable[Hashable] | Hashable, validate: bool = True, *, displacement_vector: int | float | bool | complex | bytes | list | tuple | ndarray | generic | ArrayBox | InterfaceTensor | Tensor | Number | None = None, barriers: Iterable[int] | None = None, odd_part_dropped: bool = False)¶

Bases: GaussianStatePrepBase

Prepare a fermionic Gaussian state, possibly mixed, from its Majorana covariance matrix.

The state is the even Gaussian state \(\rho\) whose only non-trivial correlations are

\[\Lambda_{\mu\nu} = i\, \mathrm{Tr}(\rho\, c_\mu c_\nu), \quad \mu \neq \nu,\]

with the Jordan-Wigner Majorana operators \(c_{2k} = Z_{<k} X_k\) and \(c_{2k+1} = Z_{<k} Y_k\) of its wires. It is pure when \(\Lambda^2 = -\mathbb{1}\) and mixed otherwise. Mixed Gaussian states arise as the reduced state of a matchgate circuit on a contiguous block of its wires (see matchcake.covariance_matrix()), as thermal states of free-fermion Hamiltonians and as inputs with classical uncertainty on the occupation of the modes.

The covariance matrix is given as a (2n, 2n) matrix, or as a (B, 2n, 2n) batch of matrices. Gradients flow through it.

A state without a definite fermion parity also has a displacement vector \(d_\mu = \mathrm{Tr}(\rho\, c_\mu)\), given with displacement_vector. Such a state obeys Wick’s theorem in the algebra extended by the parity mode, with the bordered matrix

\[\begin{split}\widetilde\Lambda = \begin{pmatrix} \Lambda & d \\ -d^\top & 0 \end{pmatrix}.\end{split}\]

It arises as the reduced state of a matchgate circuit started from a product state with superposed qubits, on a block of wires that starts at the first wire of the register. The displacement vector is then the second parameter of the operation and gradients flow through it as well.

A state obtained by tracing out wires that are not the last wires of a register also carries gate barriers, given with barriers and described in barriers. They are set by reduced_state and partial_trace of nif.qubit and by matchcake.reduced_state(), and they make the device refuse the gates and the observables whose result would not be the one of the reduced state of the qubits.

The operation is supported natively by nif.qubit. Its decomposition() is a pennylane.QubitDensityMatrix built from the dense density matrix, which can be queued on a mixed-state simulator such as default.mixed to get a dense reference for small systems. A state with a nonzero displacement vector or with barriers has no such decomposition.

to_wires(wires: Wires | Iterable[Hashable] | Hashable) → GaussianStatePrep¶

Return the same state on wires, with the wires this state does not act on in \(|0\rangle\).

The wires of this state must appear in wires in the same relative order. The Jordan-Wigner strings that run through the added wires then act on \(|0\rangle\) and are trivial, so the fermionic modes of this state are the qubits of the same wires in the larger register. For the same reason the displacement vector keeps its entries on the wires of this state, and it vanishes on the added wires since \(\langle 0 | X | 0 \rangle = \langle 0 | Y | 0 \rangle = 0\). Gradients flow through the covariance matrix and the displacement vector.

A barrier stays just before the wire it precedes. A wire added in the place of traced-out wires is therefore on the left of their barrier, and a wire added after the last wire is on the right of every barrier.

Parameters:

wires (WiresLike) – The wires of the new state. They must contain every wire of this state.

Returns:

This state if wires already matches its wires, otherwise a new GaussianStatePrep on wires.

Return type:

GaussianStatePrep

Raises:

ValueError – If wires misses a wire of this state or lists them in another order.

matchcake.operations.state_preparation.gaussian_state_prep_base module¶

class matchcake.operations.state_preparation.gaussian_state_prep_base.GaussianStatePrepBase(*params: int | float | bool | complex | bytes | list | tuple | ndarray | generic | ArrayBox | InterfaceTensor, wires: Wires | Iterable[Hashable] | Hashable | None = None, id: str | None = None)¶

Bases: StatePrepBase

Base class of the state preparations that a non-interacting fermionic device evolves natively.

Such a state is described by its Majorana covariance matrix

\[(\Lambda_0)_{\mu\nu} = i\, \mathrm{Tr}(\rho\, c_\mu c_\nu), \quad \mu \neq \nu,\]

and its displacement vector \(d_\mu = \mathrm{Tr}(\rho\, c_\mu)\), with the Jordan-Wigner Majorana operators \(c_{2k} = Z_{<k} X_k\) and \(c_{2k+1} = Z_{<k} Y_k\). A matchgate circuit with single-particle transition matrix \(R\) maps them to \(R^\top \Lambda_0 R\) and \(R^\top d\), which is all the device needs to compute expectation values, probabilities and samples.

Subclasses provide covariance_matrix, to_wires() and, when the state is not an even fermionic Gaussian state, displacement_vector. A state obtained by tracing out wires can also have barriers.

Variables:

DISPLACEMENT_ATOL – Absolute tolerance under which a displacement vector is considered zero.

DISPLACEMENT_ATOL = 1e-12¶
property barriers: Tuple[int, ...]¶

Positions of the gate barriers of the prepared state, in the order of its wires.

A barrier at position \(p\) sits just before the wire at position \(p\). It marks wires that were traced out there, and whose Jordan-Wigner strings are still hidden in the Majorana operators of the wires at positions \(\geq p\). The expectation value of a Pauli word is the one of the reduced state of the qubits exactly when, for every barrier, the word has an even number of \(X\) and \(Y\) on the wires at positions \(\geq p\). A device therefore refuses the gates that act on both sides of a barrier and the observables that break this rule.

Returns:

The sorted positions of the barriers, empty by default.

property covariance_matrix: int | float | bool | complex | bytes | list | tuple | ndarray | generic | ArrayBox | InterfaceTensor | Tensor | Number¶

Majorana covariance matrix \(\Lambda_0\) of the prepared state.

Returns a real antisymmetric (2n, 2n) tensor (or (B, 2n, 2n) for a batched state) with the convention

\[(\Lambda_0)_{\mu\nu} = i\, \langle\Psi|\, c_\mu c_\nu\, |\Psi\rangle, \quad \mu \neq \nu,\]

using the Jordan-Wigner mapping \(c_{2k} = Z_{<k} X_k\), \(c_{2k+1} = Z_{<k} Y_k\) (0-indexed Majoranas and qubits).

For a product state, the matrix has a simple closed form in terms of the per-qubit Bloch vectors \((x_k, y_k, z_k)\):

  • Same-qubit entries: \((\Lambda_0)_{2k, 2k+1} = -z_k\).

  • Different-qubit entries (for \(j < k\)):

    \[\begin{split}\begin{aligned} (\Lambda_0)_{2j,\,2k} &= +y_j\, p_{jk}\, x_k, \\ (\Lambda_0)_{2j,\,2k+1} &= +y_j\, p_{jk}\, y_k, \\ (\Lambda_0)_{2j+1,\,2k} &= -x_j\, p_{jk}\, x_k, \\ (\Lambda_0)_{2j+1,\,2k+1} &= -x_j\, p_{jk}\, y_k, \end{aligned}\end{split}\]

    where \(p_{jk} = \prod_{j < l < k} z_l\) is the parity-string factor (and \(p_{jk} = 1\) if \(k = j+1\)).

The remaining entries are filled by antisymmetry.

property displacement_vector: int | float | bool | complex | bytes | list | tuple | ndarray | generic | ArrayBox | InterfaceTensor | Tensor | Number¶

Displacement vector \(d_\mu = \langle\Psi|\, c_\mu\, |\Psi\rangle\) of the prepared state.

For a product state with per-qubit Bloch vectors \((x_k, y_k, z_k)\), \(d_{2k} = x_k \prod_{l<k} z_l\) and \(d_{2k+1} = y_k \prod_{l<k} z_l\). It vanishes for a computational-basis state.

Returns:

Bases: ProductState

Prepare a state by listing the gates that build it from \(|0\ldots0\rangle\).

This is a ProductState whose per-qubit amplitudes are obtained by applying the gates yielded by gate_generator to the all-zero state. Only single-qubit gate generators (one or more gates acting on individual wires) describe a product state and are therefore supported; a multi-qubit gate would entangle the qubits and cannot be represented as a ProductState.

Because it is a genuine ProductState, it works with every strategy that accepts product-state inputs (e.g. the m-Pfaffian expectation-value strategy), while still decomposing into its defining gates for the gate-based paths.
