matchcake.ml.cross_validation module¶

class matchcake.ml.cross_validation.CrossValidation(estimators: Dict[str, BaseEstimator], x: int | float | bool | complex | bytes | list | tuple | ndarray | generic | ArrayBox | InterfaceTensor | Tensor | Number, y: int | float | bool | complex | bytes | list | tuple | ndarray | generic | ArrayBox | InterfaceTensor | Tensor | Number | None = None, *, cv: Any | None = None, cross_validate_kwargs: Dict[str, Any] | None = None)¶

Bases: object

The CrossValidation class defines an object to encapsulate the handling and the outputs of scikit-learn Cross-validation module.

It can run multiple estimators one after another to test the performance of each of them in a reproducible manner.

Variables:

  • ESTIMATOR_NAME_KEY – Internal key name for estimator names.

  • INDICES_NAME_KEY – Internal key name for indices.

  • INDICES_TRAIN_KEY – Internal key name for training indices.

  • INDICES_TEST_KEY – Internal key name for testing indices.

  • estimators – The dictionary mapping estimator names to the estimator.

  • x – The independant variable.

  • y – The dependant variable.

  • cv – The Cross-Validation method. If none is passed, it will default to a StratifiedShuffleSplit with 20 splits and a train-test ration of 80-20

  • cross_validator_kwargs – Additional arguments to pass to the cross-validator. See https://scikit-learn.org/stable/modules/cross_validation.html

Initialize the Cross-Validator with the estimators to validate and the data to train it on.

Passed cross-validator kwargs can have the form: ``` {

‘return_train_score’: True, ‘return_estimator’: True, ‘return_indices’: True,

}¶

These kwargs are optional. By default, return_train_score will be True. See https://scikit-learn.org/stable/modules/cross_validation.html for information on these parameters.

param estimators:

Dictionary mapping estimator names to the estimator

param x:

Independant variable to be processed.

param y:

Dependant variable to be processed.

type y:

Any tensor-compatible object.

param cv:

The cross-validator. Will use a StratifiedShuffleSplit with 20 splits by default.

type cv:

An initialised cross-validator.

ivar cross_validator_kwargs:

Additional arguments to pass to the cross-validator. See https://scikit-learn.org/stable/modules/cross_validation.html .

type cross_validator_kwargs:

A mapping between the arguments and their True/False value.

run(verbose=True) → CrossValidationOutput¶

Run the cross-validation. It will run all estimators with the same data and cross-validation method. Outputs of the cross-validation will be saved in a CrossValidationOutput object.

Parameters:

verbose – If to show progress.

Returns:

A CrossValidationOutput object.
