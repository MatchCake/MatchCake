matchcake.measurements.covariance_matrix.covariance_matrix(wires: Wires | Iterable[Hashable] | Hashable | None = None, gate_barrier: bool = True) → CovarianceMatrixMP¶

Majorana covariance matrix of the state on a subset of the wires, the other wires being traced out.

The covariance matrix is \(\Lambda_{\mu\nu} = i\, \mathrm{Tr}(\rho\, c_\mu c_\nu)\) for \(\mu \neq \nu\), with the Jordan-Wigner Majorana operators \(c_{2k} = Z_{<k} X_k\) and \(c_{2k+1} = Z_{<k} Y_k\) of the kept wires. After a matchgate circuit on a computational-basis state, the reduced state on a contiguous block of wires is a fermionic Gaussian state, generally mixed, and its covariance matrix describes it completely. The result can be passed to GaussianStatePrep to start another circuit from the reduced state:

@qml.qnode(qml.device("nif.qubit", wires=4))
def circuit():
    qml.BasisState([1, 0, 1, 0], wires=range(4))
    mc.operations.CompRxRx([0.3, 0.7], wires=[1, 2])
    return mc.covariance_matrix(wires=[0, 1])

@qml.qnode(qml.device("nif.qubit", wires=2))
def follow_up(reduced_covariance):
    mc.GaussianStatePrep(reduced_covariance, wires=[0, 1])
    mc.operations.CompRyRy([0.1, 0.2], wires=[0, 1])
    return qml.expval(qml.Z(0))

follow_up(circuit())

The kept wires must form a contiguous block listed in register order. Otherwise the Jordan-Wigner strings of the kept Majorana operators run through the removed wires, and the principal submatrix describes the reduced state of the fermionic modes, which is not the reduced state of the qubits. A matrix cannot carry the gate barriers that make this safe: use matchcake.reduced_state() to get the reduced state with its barriers, or pass gate_barrier=False to get the covariance matrix of the fermionic reduced state, with a warning.

The measurement is analytic, differentiable, and supported by nif.qubit as well as by the dense simulators (default.qubit, default.mixed).

Parameters:

  • wires (Optional[WiresLike]) – The wires to keep. None keeps all the wires of the device.

  • gate_barrier (bool) – Whether to refuse kept wires that are not a contiguous block in register order. With False, the covariance matrix of the fermionic reduced state is returned for them.

Returns:

The measurement process, of result shape (2k, 2k) for k kept wires.

Return type:

CovarianceMatrixMP

matchcake.measurements.reduced_state.reduced_state(wires: Wires | Iterable[Hashable] | Hashable | None = None, *, reduced_wires: Wires | Iterable[Hashable] | Hashable | None = None, gate_barrier: bool = True) → ReducedStateMP¶

Reduced state on a subset of the wires, the other wires being traced out, as a state preparation.

The result is the GaussianStatePrep returned by reduced_state of nif.qubit: the covariance matrix of the kept wires, the displacement vector when the state has one, and the gate barriers left by the removed wires. It is queued as the first operation of another circuit to continue the simulation on the kept wires:

@qml.qnode(qml.device("nif.qubit", wires=4))
def circuit():
    qml.BasisState([1, 0, 1, 0], wires=range(4))
    mc.operations.CompRxRx([0.3, 0.7], wires=[1, 2])
    return mc.reduced_state(wires=[0, 1, 3])

@qml.qnode(qml.device("nif.qubit", wires=3))
def follow_up(state):
    qml.apply(state)
    mc.operations.CompRyRy([0.1, 0.2], wires=[0, 1])
    return qml.probs()

follow_up(circuit())

Here wire 2 is removed between wires 1 and 3, so the state has a barrier before its last wire. The device then raises a DeviceError for a gate on the last two wires and for an observable such as qml.X(1) @ qml.X(2), whose results would not be those of the reduced state of the qubits. Gates on one side of a barrier, probabilities, samples and the observables with an even number of \(X\) and \(Y\) on the right of every barrier are exact. With gate_barrier=False, the state is returned without barriers and with a warning.

The measurement is analytic, differentiable with torch, and only supported by nif.qubit.

Parameters:

  • wires (Optional[WiresLike]) – The wires to keep, in the order of the device. None keeps all the wires.

  • reduced_wires (Optional[WiresLike]) – Wire labels of the returned state preparation. Defaults to range(k) for k kept wires.

  • gate_barrier (bool) – Whether the returned state preparation carries its gate barriers.

Returns:

The measurement process, whose result is a GaussianStatePrep.

Return type:

ReducedStateMP
